      <H2 id="s8" n="8">遙測管線：從 emit 到落地</H2>
      <p>
        遙測不是十個各自獨立的資料夾，是七條各自有落地終點的事件家族。
        每個家族都走同一種形狀：功能模組呼叫一個具名事件（發生），事件交給該行程自己那份
        port 介面，port 由一支 adapter 在開機時接上真正的後端（轉接），中間可能經過驗證、緩衝或聚合這類管線（管線），最後在某個行程邊界落地（落地）。
        <code>events.json</code>
        依這個形狀從呼叫圖抓出七十筆事件，其中五支 port 方法沒有任何呼叫者，判定死碼。8.1
        先把這份目錄攤開來看；8.2 到 8.8 逐家族講清楚它怎麼發生、怎麼接線、能不能被丟；8.9
        把七個家族收進一張接線總表。
      </p>
      <p>
        三條管線共用一個形狀。呼叫端只認 port，port 是型別與方法名的清單，附一份什麼都不做的預設，所以關掉遙測不必改呼叫端；adapter
        是開機時把 port 接上真後端的工廠，缺欄位當場丟錯，不等第一筆事件；中間有沒有翻譯、緩衝或聚合層，是各管線唯一的差別。下面先畫這個形狀，之後每個家族只講它跟形狀不一樣的地方。
      </p>

      <H3 id="s8-1" n="8.1">事件目錄：七十筆事件、七個家族、五支死碼</H3>
      <p>
        這份目錄不是逐資料夾列檔案，是逐呼叫點列事件：每一列是呼叫圖裡一個真的打進某支
        port 方法的呼叫點，欄位是事件名稱、發生的 <code>file:line</code>、呼叫的 port
        方法、接手的 adapter、中間經過的管線、落地的 sink、掉點或重試政策，最後標一個所屬家族。
        <code>events.json</code> 的 <code>families</code> 欄位列出這七個家族的名字，每一筆事件都恰好歸屬其中一個。下面這棵判別樹只看 adapter 欄位就把七十筆分成七種，每個出口寫這一種的 port、管線與落地，怎麼接在各自的工具裡見 8.2 到 8.8。
      </p>
      <Dag svg={ROUTER} />
      <p>

        no-op 實作，換掉遙測開關就是把整份 port 換成 no-op。
        <Peek snip="t-noop">no-op port</Peek>
        adapter 才是真正接後端的那一支，在開機時把 port 接上實體連線，接錯線或設定缺欄位會在這一刻就炸出來，不用等到第一筆事件送不出去才發現。
        <Peek snip="t-adapter">adapter 建立前檢查</Peek>
        host 行程自己的 <code>SandTelemetry</code> port 有三十一支具名方法，
        <code>reportBotBlock</code>、<code>reportBoxBootStage</code>、
        <code>reportExecDaemonRestart</code>、<code>reportSupervisorRestart</code>、
        <code>reportJournalOutcome</code> 這五支在整棵樹裡找不到任何呼叫者，是這份<Term k="reconstruction">重建疊層</Term>裡沒人用過的介面，跟出廠行為無關。
