  <H3 id="s2-1" n="2.1">主行程只起殼</H3>
  <p>
    stub 先載 <code>main-core</code>，等 <code>remainderDue</code>，再載 <code>main-app</code>。三個 cjs 不是三個 OS process。
    主行程 fork 出 coordinator 之後，自己的責任是轉發。模型迴圈不在桌面 main。

  <H3 id="s2-2" n="2.2">畫面靠 preload 轉手</H3>
  <p>
    Preload 暴露 <code>desktop</code> 與 <code>coordinatorPort</code>，並聽 <code>sand:coordinator-port</code>。
    畫面呼叫 <code>invoke("sand:coordinator-port-request")</code>。main 把 <code>event.ports[0]</code> 交回去。畫面看不到 gateway 位址。
  </p>
  <H3 id="s2-3" n="2.3">host-main 在 box 內 listen</H3>
  <p>
    Laptop 連 box：<code>resolveGatewayConnection</code> → <code>GrokBotService.EnsureSandBox</code>，除非已設 <code>SAND_HOST_GATEWAY_URL</code>。空 URL throw。這段實作在 freeze 未列的 <code>main-app.cjs</code>，見 ARCHITECTURE。
    Box 內 <code>runHostMain</code>：<code>acquireHostLock</code> → <code>SandHost.start</code> → <code>startGatewayServer</code> → <code>listen(port ?? 0)</code> → <code>writeGatewayDiscovery</code>。
    <code>--box-copy-in</code> 在開頭 <code>process.exit</code>，不開 gateway。
  </p>
  <H3 id="s2-4" n="2.4">box-exec 不在這份 asar</H3>
  <p>
    0.47 laptop asar 沒有 <code>dist/host/</code>，也沒有 box-exec 啟動碼。<code>runHostMain</code> 不 spawn box-exec。ARCHITECTURE 把它畫在 VM 旁。不能把 0.18「host 生 box-exec」當成這份安裝包的事實。
  </p>
  <H3 id="s2-5" n="2.5">coordinator 用 fork 起，三條 MessagePort</H3>
  <p>
    <code>launchCoordinator</code> 以服務名 <code>sand-node-agent-coordinator</code> 做 <code>fork</code>，建 control、rendererData、mainData 三條 channel，一次 <code>postMessage</code> 進子行程。
    <Peek snip="launcher">三埠</Peek>
    之後 coordinator 對 gateway 做 <code>POST /api/sendPrompt</code>。
  </p>
