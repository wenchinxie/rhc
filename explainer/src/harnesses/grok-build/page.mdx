  <h1>Grok Build</h1>
  <H2 id="s-parts" n="1">元件</H2>
  <p>點這個工具只看這一輪要啟動的七個槽。登入的走法與決策樹在第四節。</p>
  <H3 id="s-parts-session" n="1">對話</H3>
  <p>對話狀態在 <code>xai-chat-state</code>。這一輪發生過的事件在 <code>xai-grok-session-events</code>。</p>
  <H3 id="s-parts-prompt" n="2">提示</H3>
  <p>系統提示、skill、<code>AGENTS.md</code> 在 <code>xai-grok-agent/src/prompt/</code>。提醒政策在 <code>xai-grok-agent/src/system_reminder.rs</code>。<code>xai-grok-agent/src/lib.rs</code> 把工具、系統提示、提醒、壓縮、模型設定包成一個 <code>Agent</code>。</p>
  <H3 id="s-parts-model" n="3">模型</H3>
  <p>模型表在 <code>xai-grok-models</code> 的 <code>default_models.json</code>。呼叫端先選鑰匙再打模型，在 <code>xai-grok-shell/src/agent/config.rs</code> 的 <code>resolve_credentials</code>。</p>
  <H3 id="s-parts-auth" n="4">登入</H3>
  <p>打模型之前，<code>resolve_credentials</code> 先看模型自帶鑰匙、provider、session，然後才看 <code>XAI_API_KEY</code>。都沒有，才進 <code>run_auth_flow</code>。一般 xAI 帳號的主幹是瀏覽器。Chrome 打開 <code>auth.x.ai</code>，跳回 <code>127.0.0.1</code>，票寫進 <code>~/.grok/auth.json</code>，模式仍是 <code>AuthMode::Oidc</code>。</p>
  <p><Term k="auth-port">AuthCredentialProvider</Term> 的 <Term k="snapshot">snapshot</Term> 是現在會送出去的 bearer。HTTP 只問這個，不再跑登入。<code>AuthMode</code> 有 <code>Oidc</code>、<code>ApiKey</code>、<code>External</code>，以及舊的 <code>WebLogin</code>。issuer 就算是 <code>https://auth.x.ai</code>，<code>build_grok_auth</code> 仍寫 <code>AuthMode::Oidc</code>。<code>config.oidc</code> 有值才是另一個 issuer。<code>is_configured</code> 只看這塊。沒有這塊時，預設仍有 xAI oauth2。</p>
  <p><code>run_auth_flow_steps</code> 的順序是固定的。記憶體裡有未過期、issuer 相容的票，直接用。已過期才 refresh。暫時失敗且磁碟上還有 refresh token，就把過期票交回，不開瀏覽器。設了 <code>auth_provider_command</code> 就先跑那個程式。成功就結束。失敗才繼續瀏覽器。<code>config.oidc</code> 有值就走那個 issuer 的 loopback，不再選 device-code。</p>
  <p>剩下的是 xAI oauth2。<code>resolve_device_flow</code> 看 CLI、<code>GROK_LOGIN_DEVICE_FLOW</code>、config、遠端旗標，最後 <code>default(false)</code>。預設不打裝置碼。被打開時才 POST <code>/oauth2/device/code</code>。404 是 <code>DeviceCodeError::NotEnabled</code>，下一行仍是 loopback。loopback 綁 <code>127.0.0.1</code>，redirect 是 <code>http://127.0.0.1:&#123;port&#125;/callback</code>。<code>build_authorize_url</code> 用 discovery 的 <code>authorization_endpoint</code>。callback 的 code 用 <code>authorization_code</code> 換票。<code>AuthManager::update</code> 寫入 <code>~/.grok/auth.json</code>。</p>

  <p><code>AuthMode::Oidc</code> 也用來存 xAI 自己的瀏覽器登入。分辨是不是 xAI，要再看 <code>oidc_issuer</code> 是不是 <code>https://auth.x.ai</code>。device-code 的 404 會退回 loopback。其他 device 錯誤直接返回。</p>
  <H3 id="s-parts-tools" n="5">工具</H3>
  <p>內建工具在 <code>xai-grok-tools</code>，Grok Build 那組在 <code>implementations/grok_build/</code>。MCP 是 <code>xai-grok-mcp</code>。沙箱在 <code>xai-grok-sandbox</code>。</p>
  <H3 id="s-parts-turn" n="6">一輪</H3>
  <p>把 <code>Agent</code> 跑起來、收回工具結果再送回去，在 <code>xai-grok-shell</code>。子代理怎麼對上，在 <code>xai-grok-subagent-resolution</code>。</p>
  <H3 id="s-parts-rest" n="7">旁邊的槽</H3>
  <p>記憶是 <code>xai-grok-memory</code>。對話太長的政策在 <code>xai-grok-agent/src/compaction.rs</code>。Hook 是 <code>xai-grok-hooks</code>。工具用的鑰匙在 <code>xai-grok-secrets</code>。紀錄在 <code>xai-grok-telemetry</code>。</p>
