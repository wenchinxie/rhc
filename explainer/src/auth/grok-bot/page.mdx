  <H2 id="top" n="">Grok Bot</H2>
  <p>兩張票，兩個行程。安裝包 <code>app.asar</code> 只做桌面 Cursor 登入。VM host zip 只換短命推論票。兩邊都不包含對方的路徑。<code>host/ports</code> 沒有 auth。旁邊功能呼叫 <code>start()</code> 交出去的 <code>getAccessToken</code>。</p>
  <p>桌面票是 <code>cursor-access-token</code> 與 <code>cursor-refresh-token</code>，在 Electron userData 的 <code>sand-secrets.json</code>，值經過 <code>safeStorage</code>。畫面呼叫 <code>loginCursor</code> 拿到的是狀態，不是這兩張原文。</p>
  <p>host 票在 RAM 的 InferenceCredentialStore。來源是環境變數 <code>SAND_INFERENCE_RENEWAL_CREDENTIAL</code>，或開發用的 <code>SAND_DEV_INFERENCE_TOKEN_FILE</code>。host 不讀 <code>sand-secrets.json</code>。0.47 的 host 另外留 <code>grokBotToken</code>。InferenceService 的 Stream 會把 Authorization 換成它。0.18 只有 <code>getAccessToken</code>。</p>
  <p>渲染行程呼叫 <code>cursorAccount.login()</code>，對到 edge 的 <code>loginCursor</code>。0.47 安裝包裡同一支在 <code>dist/electron-main/main-app.cjs</code>，preload 走 <code>dune-rpc</code>。這個前綴是 IPC 頻道名，不是 auth 協定。</p>
  <p><code>createDefaultLoginManager</code> 看後端是不是開發站。開發站用 <code>SandBackendLoginManager</code>。否則用 <code>LoginManager</code>，redirect 是 <code>sand</code>。兩邊都開 <code>/loginDeepControl</code>，帶 PKCE challenge 與 uuid，然後 <code>GET /auth/poll</code>。404 繼續等。連續三次其他失敗就放棄。200 且 JSON 同時有 <code>accessToken</code> 與 <code>refreshToken</code> 才算成功。成功後寫進 <code>sand-secrets.json</code>。0.47 還可能寫 <code>cursor-selected-team-id</code>。0.18 是兩把鑰匙的平面表。</p>
  <p>host 在另一份 zip。<code>authExtension.start</code> 讀行程環境。有開發 token 檔就讀檔。否則用續期憑證 POST <code>/sand-box/inference-credential</code>。回應的 <code>accessToken</code> 只放記憶體。沒有憑證時 renewer 仍會啟動，<code>getAccessToken</code> 丟等待錯誤。0.47 在還有 box 憑證時才聽 <code>/tmp/sand-identity.sock</code>。客體 <code>POST /v1/tokens/oidc</code> 被轉去 <code>/cloud-agent/identity-token/sand-box</code>。這條不是推論用的短票。安裝包 asar 裡沒有這些名字。</p>
